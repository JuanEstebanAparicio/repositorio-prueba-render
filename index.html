Hice un git push y Render hizo el resto: construyó la imagen, la desplegó y me dio esta dirección pública.

Lo que pasó entre el push y esta página

  1. Push a GitHub Subí index.html, style.css y el Dockerfile al repositorio.
  2. Render construye Detecta el Dockerfile y arma la imagen con nginx.
  3. Render publica Arranca el contenedor y detecta el puerto abierto.
  4. La URL responde Cualquier persona con el enlace puede ver esta página.
